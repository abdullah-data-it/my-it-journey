# رحلة تعلّمي في تقنية المعلومات

عبدالله يوسف — طالب تقنية معلومات (المستوى الرابع)، وعندي دبلوم محاسبة وعمل ميداني في قراءة العدادات وتحصيل الفواتير.

أوثّق هنا رحلتي العملية: SQL وقواعد البيانات أولًا، ثم Python وتحليل البيانات، ثم أنظمة ERP مثل Odoo.

هدفي: وظيفة في تحليل البيانات أو تشغيل وتطوير أنظمة ERP.
